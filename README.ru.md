# jswitcher

[English](README.md) · **Русский**

Маленькая программа для строки меню macOS, которая исправляет текст, набранный не в той раскладке (русская ↔ английская). Открытая замена Punto Switcher, код которой можно проверить.

- Набрали `ghbdtn` и пробел → получится «привет », раскладка переключится на русскую.
- **Одиночное нажатие левого Control** конвертирует последнее слово в другую раскладку и переключает её. Повторный Control возвращает слово обратно.
- **Control сразу после автоисправления** отменяет его.
- **Выделить текст и нажать Control** — конвертируется всё выделенное.

## Приватность и безопасность

Переключатель раскладки видит все нажатия, поэтому главное — доверие:

- **Не ходит в сеть.** В коде нет сетевого кода. `scripts/build.sh` падает, если бинарник связан с `Network`/`CFNetwork` или ссылается на `URLSession`, сокеты и т. п.
- **Не трогает буфер обмена.** Выделенный текст читается через Accessibility только в момент нажатия Control, заменяется на месте и сразу забывается.
- **Не сохраняет набранный текст.** Ни на диск, ни в лог, ни в буфер обмена. В памяти лежат только коды клавиш текущего и предыдущего слова. В релизной сборке логов нет совсем.
- **Нет сторонних зависимостей и entitlement-ов.**
- **Не трогает поля пароля** (Secure Input).
- Нужно одно разрешение: **Универсальный доступ** (Accessibility). «Мониторинг ввода» не нужен.

## Требования

macOS 13 Ventura или новее, Apple Silicon или Intel (универсальный бинарник).

Протестировано на macOS 14 (Apple Silicon). На macOS 13 и на Mac с Intel должно работать, но ещё не проверялось — сообщайте о проблемах.

## Установка

1. Скачайте `jswitcher-<версия>.zip` из [Releases](https://github.com/juggle73/jswitcher/releases). Сборки подписаны Developer ID и нотаризованы Apple. По желанию сверьте SHA-256 с указанным в описании релиза:
   ```sh
   shasum -a 256 jswitcher-<версия>.zip
   ```
2. Распакуйте, перенесите `jswitcher.app` в `/Applications`, запустите.
3. macOS попросит **Универсальный доступ**: включите jswitcher в «Системные настройки → Конфиденциальность и безопасность → Универсальный доступ».

Пока прав нет, в строке меню горит `⚠︎`. В меню есть пункты «Открыть настройки доступа…» и «Перезапустить jswitcher». Обычно после выдачи прав программа начинает работать сама в течение 2 секунд.

**Автозапуск.** При первом запуске jswitcher добавляет себя в объекты входа. Выключить: «Системные настройки → Основные → Объекты входа» (сам он себя туда больше не добавит). Полностью выключить jswitcher — меню → «Выход».

## Управление

| Действие | Результат |
|---|---|
| Слово + пробел / Enter / Tab | Если слово набрано не в той раскладке — исправляется, раскладка переключается |
| Левый Control (одиночное нажатие) | Конвертирует текущее слово. Если слово уже закончено пробелом — конвертирует предыдущее. Иначе просто переключает раскладку |
| Левый Control сразу после автоисправления | Отменяет исправление |
| Выделить текст + левый Control | Весь выделенный фрагмент меняет раскладку: каждый символ заменяется на тот, что стоит на той же клавише в другой раскладке (запятая ↔ «б» и т. д.; пробелы и переносы не меняются). Раскладка переключается |
| Control+Option вместе (нажать и отпустить, без других клавиш) или меню «Пауза» | Пауза: нет автоисправления, левый Control работает. Программы из списка исключений всегда на паузе |

После Enter и Tab предыдущее слово не конвертируется: сообщение уже отправлено или фокус ушёл. Control в этом случае только переключает раскладку.

Иконка в строке меню:
- `EN` / `RU` — программа работает;
- серые зачёркнутые E̶N̶ / R̶U̶ — пауза (вручную или в программе из списка исключений);
- `—` — активна другая раскладка, например иврит; программа ничего не делает;
- `⚠︎` — нет прав.

Работают раскладки ABC (или U.S.) и Russian (или «Русская – ПК»).

### Исключения

В программе из списка исключений jswitcher на паузе: нет автоисправления, левый Control работает как везде. Список редактируется в меню → «Исключения…»: «Добавить приложение…», «Из запущенных ▾», «−». По умолчанию в списке только Terminal. Список хранится в `~/Library/Preferences/io.github.juggle73.jswitcher.plist`.

## Как принимается решение

Когда слово закончено, проверяются оба прочтения нажатых клавиш, например `ghbdtn` / «привет»:

1. Слова с цифрами, `@`, `_`, `://` не трогаются никогда.
2. Короткие слова (1–2 буквы) исправляются только по спискам частых коротких слов (`b` → «и», «шз» → `ip`).
3. Слова из 3–4 заглавных букв и со смешанным регистром исправляются, только если другое прочтение — частое слово: «ЫУЕ» → `SET`, но `API`, «НДС», `getUser` не трогаются.
4. Слово, известное в набранной раскладке, не трогается — кроме случая, когда оно там редкое, а в другой частое (`dct` → «все»).
5. Слово, известное в другой раскладке, исправляется. Английские сокращения распознаются (`don't`).
6. Если ни один словарь не знает ни одного прочтения (от 4 букв), решает статистика буквенных триграмм (`gthtcj,hfk` → «пересобрал»).

## Сборка из исходников

Нужен Xcode 16 (Swift 6).

```sh
scripts/build.sh                 # тесты, универсальная сборка, подпись, проверки → build/jswitcher.app
cp -R build/jswitcher.app /Applications/
```

`scripts/build.sh`:
1. прогоняет тесты;
2. собирает универсальный (arm64 + x86_64) release-бинарник;
3. собирает `build/jswitcher.app` и подписывает с hardened runtime — первым сертификатом «Developer ID Application» из «Связки ключей» (или `$JSWITCHER_SIGN_IDENTITY`), иначе ad-hoc;
4. проверяет, что в бинарнике нет сетевых символов и entitlement-ов.

С подписью ad-hoc macOS забывает право «Универсальный доступ» после каждой пересборки: удалите jswitcher из списка кнопкой «−» и выдайте право заново.

### Релизы

```sh
# один раз: сохранить учётные данные для нотаризации в «Связке ключей»
xcrun notarytool store-credentials jswitcher-notary --apple-id <apple-id> --team-id <team-id>

scripts/release.sh
```

`scripts/release.sh` подписывает с меткой времени, отправляет на нотаризацию, прикрепляет результат и создаёт `build/jswitcher-<версия>.zip` и его SHA-256. В сеть ходят только эти инструменты сборки (серверы меток времени и нотаризации Apple), сама программа — никогда.

## Словари

| Файл | Содержимое | Источник |
|---|---|---|
| `dict_en.bin`, `dict_ru.bin` | 200 000 самых частых слов | [Hermit Dave FrequencyWords](https://github.com/hermitdave/FrequencyWords) (`en_full`, `ru_full`, 2018) |
| `dict_en_top.bin`, `dict_ru_top.bin` | 20 000 самых частых слов | там же |
| `ngram_en.bin`, `ngram_ru.bin` | модели буквенных триграмм, обученные на 200 000 словах | там же |
| `dict_tech.bin` | технические термины (docx, json, golang, kubectl, nginx…) | [cspell-dicts](https://github.com/streetsidesoftware/cspell-dicts), коммит `db01cf7` |

Формат: LZFSE-сжатый отсортированный список слов; модели триграмм — LZFSE-сжатые таблицы логарифмов вероятностей.

Как пересобрать: положите `en_full.txt` и `ru_full.txt` из FrequencyWords в `data/raw/` (папка в `.gitignore`) и выполните команды из раздела [Word data](README.md#word-data) английского README.
